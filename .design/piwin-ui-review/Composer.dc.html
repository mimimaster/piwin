为什么“层级”看不出来：八个名字，一个颜色
主题运行时往 <html> 上写了约 150 个 CSS 变量，其中这八个语义完全不同的表面全部解析成同一个值（墨面）：
--panel#201d19 --card#201d19 --composer#201d19 --user-bubble#201d19 --control#201d19 --surface#201d19 --surface-inset#201d19 --surface-overlay#201d19
“抬起的卡片”“凹陷的输入”“用户气泡”在颜色上永远无法区分，因为它们是同一个值的八个别名。而舞台到抬升层的对比只有 1.06:1——任何一处投影被裁掉或被覆盖，那块面就彻底贴平了。

建议：砍掉别名、只留 --surface-1…4，并把抬升层拉开到 1.13:1（墨面 #262218，纸面舞台降到 #f5f2ea 让白卡片浮起来）。样式表里还有 620 处写死的色值在绕过这套 token，同一批一起清。

建议：标题栏只留全局明暗一个开关
石板的“砚 / 纸”是一次性口味设置，属于设置 → 外观；它不需要常驻在标题栏上，更不该和全局主题长得一样。留下的那个开关补上 aria-label 和 aria-pressed。顺带一提，--signal-rail-width: 46px 这个 token 还在 tokens.css 里，而规范第 7.2 节已经明确删掉了导航轨——可以清掉了。
