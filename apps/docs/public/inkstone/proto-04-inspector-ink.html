行内评论三态
悬停任意可评论行才会露出评论图标按钮，已有评论的行常显该按钮并保持背景轻微染色。三态：新建（空文本框 + 取消/添加评论）、查看（已有文字 + 删除/编辑）、编辑（预填文本框 + 取消/保存）。发消息时会把本文档全部暂存评论合并进提示词文本，随后清空——这是喂给 Agent 的一次性素材，不是长期批注库。
