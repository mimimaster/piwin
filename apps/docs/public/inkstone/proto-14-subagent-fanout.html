① 扇出图（≥2 个子代理同批派出）

左侧主代理节点只做展示（不可点击）；右侧每个子代理一行，固定 46px 高。连线颜色即状态： 运行中＝琥珀虚线流动，排队＝点线，完成＝松绿实线，失败＝赤色。点击子代理行在卡片内展开下方的密集预览，选中的那条线加粗。

单个子代理不画图，沿用 proto-13 的单行（③）。已全部结束且无待处理的组，仍按 proto-13 规则折叠成头部一行。

② 窄卡片（容器宽 ≤ 520px）

主代理节点收起，连线退化为左侧树形导轨；行高与内容不变，只换左栏。

③ 预览里刻意不做的事

不渲染 Markdown、不渲染工具卡片 / diff / 文件变更条 / artifact / 引用 / 图片；没有「打开完整会话」。 每一步就是一行：时间 · 动作 · 目标 · 结果。结论用纯文本原样展示（保留换行）。 唯一的交互是权限确认行（不能被折叠藏起来）。
