## 1. 会话树与冷存储归档 (Session Tree & Archiving)

### 1.1 告别混乱的线状聊天列表
传统聊天工具采用单向线状结构，分支尝试或错误回退会导致上下文混乱。

在 Piwin 中：
- **原生支持会话树 (Session Tree)**：支持在任意历史节点分叉出新的探索分支，回溯实验互不干扰；
- **冷存储归档机制 (Cold Storage)**：长期使用后，积累的大量会话容易拖慢加载并造成视觉杂乱。Piwin 提供了优雅的**归档管理器**。

![会话归档管理界面](https://img.yorickjue.com/file/1789928362764_image.png)

### 1.2 归档的核心价值
1. **工作区整洁清爽**：已完结的需求与临时调试分支一键归档，侧边栏仅保留当前活跃的进行中项目；
2. **知识资产永不丢失**：归档会话完整保留所有消息、工具日志与产出的 Artifact，支持随时全局检索与一键重新激活；
3. **宿主存储优化**：冷存储数据异步持久化，极大降低主界面的内存占用与启动加载开销。

## 2. 全景用量统计 (Token Usage & Analytics)

> *“毋须多言，一眼看尽每一分钱花在哪里。”*

![用量统计：缓存命中率与调用明细](/images/readme/usage.jpg)


### 2.1 统计维度与指标
点击桌面端侧边栏或设置中的 **「用量统计」**，即可查阅实时生成的数据看板：

- **全通道模型消耗对比**：详细列出 Claude 3.7 / 3.5 Sonnet、OpenAI o3 / GPT-4o、DeepSeek-V3 / R1、Gemini 2.5 等各模型的调用频次与总 Token；
- **输入、输出与缓存细分**：
  - `Input Tokens`（常规输入）
  - `Cache Read / Cache Write`（前缀缓存命中与写入，直观检验 `pi-deepseek-cache` 等扩展的省钱效果）
  - `Output Tokens`（生成输出）
- **多代理角色分摊**：精准呈现 Lead 主控、Scout 侦察兵、Sidekick 执行节点各自占用的费用比例，便于优化编排方案。
