# Devin 授权与 Token 获取指引

> **一键授权，自动解锁 Web 搜索与代码检索两大能力**  
> 在 Piwin 中，你完全不需要复杂抓包！通过内置的 **Devin OAuth 一键授权**，系统会自动获取并配置凭据，直接解锁 **Web 搜索 (web_search)** 与 **代码语义检索 (code_search)**。

---

## 1. 为什么推荐接入 Devin？

在 Piwin 中，接入 Devin 凭证可以同时激活两大王牌功能：

1. **[Code Search 智能代码搜索](./code-search.md)**：深入大型代码库分析接口与调用拓扑，**0 上下文污染**，完全不占用主模型的长窗口；
2. **[Web Search 实时网络搜索](./web-search.md)**：毫秒级检索最新技术文档与 GitHub Issue，返回干净高密度的结构化网页正文。

一套凭证，两项能力全面开箱即用，响应极快且无需额外开销。

---

## 2. 两种获取方式

### 方式一：Devin OAuth 一键授权（强烈推荐，全自动）

在最新版本的 Piwin 中，整个过程只需点一下：

1. 打开 Piwin 桌面客户端，点击左下角 **「设置」➔「OAuth 登录」**；
2. 在服务商列表中找到 **Devin**，点击 **「登录」**；
3. 客户端会自动调起浏览器跳转到官方登录/授权页面，完成确认；
4. 授权成功后返回 Piwin，系统会**自动保存凭据**，并**直接打通 Web 搜索与 Code Search**！

```
┌─────────────────────────────────────────────────────────────┐
│                    OAuth 账号管理 (OAuth)                    │
├─────────────────────────────────────────────────────────────┤
│  [ Devin ]           状态: 已授权 (Web 搜索 & Code Search 已打通) │
└─────────────────────────────────────────────────────────────┘
```

---

### 方式二：手动抓取 Token 填入（进阶备选）

如果你因特殊网络代理环境，或者希望手动管理 Token，也可以通过浏览器开发者工具手动提取：

1. 打开并登录你的 **Devin (原 Windsurf)** 网页端或桌面客户端；
2. 按 `F12` 打开 **开发者工具（DevTools）**，切换到 **网络 (Network)** 选项卡；
3. 在页面中随意触发一次简单的对话或交互；
4. 在网络请求列表中找到发往官方 API（带有 `api.devin.ai` 等特征）的请求；
5. 查看该请求的 **Request Headers**，复制 `Authorization: Bearer <your-token>` 中的 Token 字符串（去除 `Bearer ` 前缀）；
6. 回到 Piwin 客户端：
   - 在 **「设置 ➔ 代码搜索 (Code Search)」** 中选择手动填入并粘贴；
   - 在 **「设置 ➔ 网络检索 (Web Search)」** 中同样填入保存即可。

---

## 3. 安全与凭据管理

- 无论是通过 OAuth 自动获取，还是手动填入，所有凭证**严格加密存储在你的本地电脑**（`~/.piwin`），绝不会上传至任何第三方服务器；
- 你可以随时在客户端的「OAuth 登录」界面中点击「登出」撤销授权。
