## Inline Artifact
当前场景inline artifact实时渲染使用的十分积极，当模型判定密集信息更好preview的时候，会积极渲染，你也可以自定义触发方式更改：
![image.png](https://img.yorickjue.com/file/1789916595270_image.png)
## Canvas
一些比较大的artifact，模型会自动判定用canvas渲染，canvas渲染更稳定，报告、调研会十分积极使用canvas，这样设计也是因为我觉得这样比较容易一眼看懂，向左自动压掉对话区域，查看更方便
