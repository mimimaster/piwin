根据本项目架构，可以简单理解为前后端分离，你可以单独部署host-runtime(后端)，然后随意部署个能访问到host的壳子，因为是面向个人的agent，所以，用用websocket，随便了啦；
所以，你可以使用很自由的部署方式，由个人抉择，怎么方便怎么来，远程访问的话，我还是推荐使用tailscale，shadowrockets现在支持tailscale了，使用很方便的
