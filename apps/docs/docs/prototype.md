# Inkstone（砚）· 交互原型实机体验

**Inkstone（砚）** 是专为 Piwin 打造的东方文人审美设计语言。其核心理念在于「研墨沉淀，静水流深」，融合纸面（浅色）与墨面（深色）双面色阶、朱红主色调与金石书口线。

本页面收录了全部纯前端高保真交互原型，无外部 CDN 与网络依赖，直接在浏览器中运行。
