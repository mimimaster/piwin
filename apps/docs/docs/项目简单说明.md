这是一个面向个人使用的coding agent，基本上是通过调用pi agent的sdk实现的，作者马上改架构了，我头疼，不管了，先push吧；

```mermaid
        Security --> Work
        Subagent --> Ext

    State["本地状态<br/>~/.piwin"]
    Model["模型服务"]

    Client --> Gateway
    Engine --> Code
    Work --> State
    Ext --> Model
```
