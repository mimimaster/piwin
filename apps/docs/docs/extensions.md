# 扩展生态、内置 Skill 与 MCP 推荐

> **Agent-Runtime 级插件生态与热加载机制**  
> 深入拥抱 Pi 插件体系，内置高命中率缓存与目标管理扩展，支持无感热插拔与外部 MCP 协议扩展。

---

## 1. 核心特性：会话中热加载 (Hot Application)

传统开发工具在安装新插件后往往需要重启整个软件，导致正在进行的会话上下文丢失。

在 Piwin 中：
1. **无需中断工作**：当当前任务正在执行时安装新扩展，Piwin 会先优雅等待当前 Run 顺利结束；
2. **下一轮自动生效**：在下一轮对话开始时自动挂载并激活新拓展，完整的会话历史树与聊天记录被 100% 完整保留；
3. **扩展市场支持**：支持直接从市场搜索安装或通过 Git URL、本地路径快速加载。

## 2. 内置实用扩展深度推荐

Piwin 开箱即用集成了一批深度调优的内置扩展，聚焦于提升交互智能与降低 Token 成本：

![扩展市场实录](https://img.yorickjue.com/file/1789920107045_image.png)

### 2.1 `pi-deepseek-cache`（前缀缓存极速命中）
- **痛点**：深度思考模型（如 DeepSeek-R1 / V3、Claude）在多轮对话中如果提示词前缀频繁变动，无法命中服务商的 Prompt Cache，费用高昂且响应慢；
- **能力**：精心组织系统提示词与静态上下文结构，极大提升前缀缓存命中率（Cache Hit Rate），实测可节约 **50%~80%** 的输入 Token 支出。

### 2.2 `goal`（目标驱动与长线把控）
- 借鉴自主智能体（Autonomous Agents）的长程规划思想；
- 协助模型将复杂工程目标拆解为里程碑阶段，保持长上下文任务中的目标一致性，避免中途遗忘主线。

### 2.3 `llm-wiki`（知识工程沉淀）
- 自动提炼代码库概念图谱、核心契约与开发共识；
- 配合闪卡体系，将工程精髓沉淀为可复盘知识。

## 3. 内置 Skill（技能）体系

与扩展类似，Piwin 的内置 Skill 与日常功能深度绑定：

![内置 Skill 界面实录](https://img.yorickjue.com/file/1789920361744_image.png)

- **能力聚焦**：如 Karpathy 编码准则审查、文档规范检验、UI/UX 规范校验等；
- **开箱即用**：无需手动编写冗长 Prompt，输入框直接斜杠唤起对应技能；
- **智能调度**：主模型根据任务意图自动委托给专业技能节点执行。

---

## 4. MCP（模型上下文协议）推荐

Piwin 原生兼容主流 MCP 服务：
- **SQLite MCP**：本地数据库探查与数据分析；
- **Brave / DuckDuckGo Search MCP**：外部网络情报增强；
- **GitHub MCP**：仓库 Issue、PR 与 Release 联动管理。

依照 ADR 0033 规范，MCP 服务直接运行于 Host 用户本地环境，保持轻量高效与零损耗交互。

---

## 5. 支持的能力范围与边界规范

| 扩展能力类别 | 支持状态 | 具体表现与说明 |
| :--- | :--- | :--- |
| **Agent 工具 (Tools)** | 完全支持 | 扩展提供的自定义工具直接注册进当前 Host 工具箱，智能体可自主调用。 |
| **事件 Hook (Event Hooks)** | 完全支持 | `session_before_compact`、消息拦截、状态监听等 Hook 完整生效。 |
| **Provider 自定义扩展** | 完全支持 | 支持接入第三方模型或服务的 Provider 扩展。 |
| **交互对话框 (Dialogs)** | 完全支持 | 基础的确认（Confirm）、选择（Select）、输入（Input）与通知（Notify）弹窗正常由桌面端原生渲染。 |
| **混合界面扩展** | 部分可用 | 若扩展主要提供 Agent 工具但附带少量终端界面代码，Piwin 会标记为“部分可用”：工具能力正常工作，终端 TUI 界面被安全忽略。 |
| **纯终端 TUI 扩展** | 不支持 | 仅修改 Pi 终端 TUI、终端主题、终端快捷键、字符编辑器的扩展无法在 Desktop 中启用。 |

::: warning 关于重载方法的注意
扩展代码中自带的 `ctx.reload()` 并不会直接硬重启当前 Desktop 运行时；在桌面端中，请在扩展管理卡片上点击 **「应用到当前 Agent」** 进行平滑热生效。
:::
