# Pi 拓展

piwin 支持把兼容的 Pi 拓展应用到当前会话。当前任务正在运行时，piwin 会先等它结束，再让下一轮使用新的拓展。会话和聊天记录会保留。

支持的核心能力包括 Agent 工具、事件 Hook、Provider 和基础的确认、选择、输入、通知对话框。

如果一个拓展主要提供 Agent 工具，同时附带少量 Pi 终端界面功能，piwin 会标记为“部分可用”：Agent 能力继续工作，终端界面部分会被忽略或使用默认显示。

只修改 Pi TUI、主题、快捷键、编辑器或自定义渲染的拓展无法在 piwin Desktop 中启用。拓展自带的 `ctx.reload()` 也不会直接重载当前运行时；请使用“应用到当前 Agent”。
