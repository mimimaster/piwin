## 视觉委托说明
是为那些纯文本推理模型准备的，通过hook实现的，效果很不错，配置一个具有视觉模型能力的模型就可以使用了（可以去各家找免费视觉模型使用，比如硅基流动、openrouter、还有如果所示的那个）
