# 简单介绍
PIWIN是一款基于 **Pi SDK** 构建、原生支持 Pi 扩展生态的**私有本地化 Coding Agent 桌面端**。底层采用了 **Tauri（前端） + Node.js（后端 Host）** 的轻量架构。选择了**前后端分离**，所以玩法非常自由：

- **开箱即用（一体包）**：我已经准备好了 **Mac 一体包** 和 **Windows 一体包**，直接解压运行，不用繁琐配环境；
- **私有化与远程访问**：架构支持 Web 部署与前后端解耦，你可以把 Host 部署在自建服务器或 NAS 上，本地通过 Web 远程连；
- **移动端探索**：目前还先行提供了 **iOS 前端壳子**，随时随地用手机查看任务或下发需求；
后续还会持续适配更多平台，现阶段大伙儿可以直接用一体包尝鲜，或者走 Web 部署使用
