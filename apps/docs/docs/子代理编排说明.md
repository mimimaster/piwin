本质上是定义开发流程中分派不同角色的子代理，通过composer上下拉可选择不同自定义的编排规则，用户完全可以自定义；本项目内置两个编排规则，一个是ultra code 一个是fusion；
## ultra code
话说的漂亮，其实是定义一个scout，先去查代码关系，用这个可以隔离上下文，可以参考L站文章：https://linux.do/t/topic/2578075
## fusion
参考devin的fusion实现，就是我们传统希望的用一个sota模型规划，一个性价比高的模型执行，即“主规划模型 + 高性价比执行节点”；
