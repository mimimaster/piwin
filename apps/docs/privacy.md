# piwin shell 隐私政策

**中文** · [English](/en/privacy)

- **生效日期：** 2026 年 10 月 8 日
- **运营者：** Shanghai Hailebei Trading Co., Ltd.（Apple 开发者团队 ID：F47G63A8DM，以下称“我们”）
- **联系方式：** [github.com/mimimaster/piwin/issues](https://github.com/mimimaster/piwin/issues)

## 1. 适用范围

本政策适用于 iOS / iPadOS 应用 **piwin shell**（Bundle ID：`app.piwin.mobile`，以下称“本 App”）。

本 App 是 Piwin 桌面端（以下称“Host”）的远程客户端。Host 是你自己安装在自己电脑上、由你自己控制的软件。本 App 本身不执行代码，也不访问你电脑上的文件；所有任务都由你配对的 Host 执行。

## 2. 概要

- 本 App **没有注册或登录账号体系**。
- 我们**不运营任何接收、存储或分析你数据的服务器**，看不到你在本 App 中的任何内容。
- 本 App **不包含广告、统计分析或崩溃上报 SDK**，不追踪你（不使用广告标识符 IDFA），不出售或出租你的数据。
- 本 App 处理的数据只会去三个地方：**你的设备本身**、**你自己配对的 Host**，以及**你自己在 Host 上配置的 AI 模型 / 语音服务商**。

## 3. 本 App 访问哪些数据、用途与去向

| 数据 | 用途 | 去向 |
|---|---|---|
| 你输入的消息；你拍摄或从相册选择的图片 | 与 Agent 对话 | 发送到你配对的 Host；Host 按你的设置把对话内容交给你配置的 AI 模型服务商处理 |
| 语音听写（按住说话） | 把语音转成文字 | 由 iOS 系统语音识别转成文字（视系统设置可能在设备上完成，也可能由 Apple 处理，适用 Apple 的隐私政策）；转出的文字发送到 Host |
| Live 实时语音的音频（可选，只在你主动发起时） | 实时语音对话 | 使用 Host 签发的短期凭证，从设备直接传到你在 Host 上配置的语音模型服务商（如 OpenAI、xAI、Google）；音频只在内存中处理，本 App 不保存录音 |
| 相机画面 | 扫描 Host 配对二维码；拍照作为附件 | 二维码只在本机解析；照片只有在你选择发送时才会发到 Host |
| Host 地址与访问令牌 | 连接你的 Host | 保存在本机 iOS 钥匙串，只用于连接你的 Host |
| 本地网络 | 连接局域网中的 Host | 只用于与你的 Host 通信 |
| 会话列表缓存、草稿与 App 设置 | 离线查看、保留未发送的输入 | 只保存在本机 |
| 浏览器镜像画面 | 在手机上查看 Host 上的浏览器会话 | 网页由你的 Host 加载，画面经 Host 传到本 App；你访问的网站按其自身政策处理数据 |
| Apple 健康数据（可选） | 回答你的健康问题、生成你开启的健康摘要 | 见第 4 节 |

## 4. Apple 健康（HealthKit）数据

- **只读。** 本 App 只读取 Apple 健康数据，**从不写入或修改** Apple 健康中的任何数据。
- **需要你的授权。** 只有在你于 iOS 中授予读取权限、并在 App 中开启健康功能后，本 App 才会读取；你可以只授权其中一部分类别。可能读取的类别包括：步数、活动能量、锻炼时间、日照时间、静息心率、心率变异性、体重、体脂率、最大摄氧量、呼吸频率、血氧、手腕温度、体能训练记录、睡眠（时长、阶段、作息）和正念分钟数。本 App 读取并发送的是这些类别的**汇总摘要**（例如每日合计或平均值）。
- **在对话中使用。** 当 Agent 需要健康数据来回答你的问题时，本 App 默认**每次弹窗征求你的同意**，并显示数据将发送到哪里（本地模型或外部模型服务商）；你可以同意或拒绝，也可以在设置中改为“始终允许这台 Host”或关闭此功能。
- **后台同步（可选）。** 如果你开启“后台同步健康摘要”，iPhone 会通过 HealthKit 后台更新，在后台把每日健康摘要上传到你配对的 Host 并保存在那里，以便手机离线时也能回答健康问题，并生成你开启的定时健康摘要。
- **去向。** 健康摘要只发送到你配对的 Host。只有当你在对话中使用健康功能、或开启了定时健康摘要时，Host 才会按你的设置把相关摘要交给**你自己配置的 AI 模型服务商**进行分析；如果你在 Host 上使用本地模型，这些数据不会离开你自己的设备和电脑。
- **我们的承诺。** HealthKit 数据**不会用于广告、营销或基于使用数据的数据挖掘，不会出售，也不会与任何第三方共享**——唯一的例外是按你的指示发送给你自己配置的 AI 模型服务商。我们自己不接收、也不存储你的任何健康数据。
- **保留与删除。** 后台同步上传到 Host 的健康摘要保存在你的 Host 上，按你在 Host 中设置的保留时长（30、90、180 或 365 天）保存；关闭后台同步会同时删除这台设备已上传的摘要。已经出现在聊天记录中的摘要随对应会话保存在你的 Host 上，由你自行删除。

## 5. 数据存储与保留

- **你的设备：** 连接凭据保存在 iOS 钥匙串中；会话缓存、草稿和设置保存在本机。你可以在 App 中断开已配对的 Host，删除 App 会清除其本地缓存数据。
- **你的 Host：** 对话、附件和健康摘要等保存在你自己的 Host（你的电脑）上，由你管理和删除；我们无法访问。
- **第三方服务商：** 你发给自己配置的 AI 模型 / 语音服务商的内容，按其自身的政策保留。
- **我们：** 不保存你的任何数据。

## 6. 第三方服务

- **你配置的 AI 模型与语音服务商**（例如 OpenAI、Anthropic、xAI、Google 等）：由你自己选择，并用你自己的账号或密钥使用，按它们各自的隐私政策处理你发送的内容。我们与它们没有数据共享或合作关系，请阅读你所用服务商的隐私政策。
- **Apple：** 语音识别、HealthKit、钥匙串等 iOS 系统服务按 Apple 的隐私政策运行。
- 本 App 不集成任何广告、统计分析或崩溃上报 SDK。

## 7. 儿童

本 App 面向开发者，不面向 13 岁以下的儿童（或你所在地区法律规定的相应年龄），我们也不会有意收集儿童的个人信息。

## 8. 你的权利与选择

- 你可以随时在 iOS「设置」中关闭相机、麦克风、语音识别和本地网络权限，并在「健康」App 或「设置 › 隐私与安全性 › 健康」中撤销本 App 对任意健康类别的读取权限。
- 你可以在 App 中把健康数据的使用方式改为“每次询问”或关闭，或关闭后台同步（会删除这台设备已上传到 Host 的摘要）。
- 你可以断开已配对的 Host，或删除本 App。
- 由于我们不持有你的个人数据，查阅、更正、删除等请求通常可以直接在你的设备或 Host 上完成；如需帮助，请通过下方渠道联系我们。你依据所在地法律（例如《中华人民共和国个人信息保护法》、欧盟 GDPR）享有的权利不受影响。

## 9. 安全

连接凭据保存在 iOS 钥匙串中。通过公网连接 Host 时，请使用 `wss://`（TLS 加密），并妥善保管 Host 的访问令牌。

本政策如有变更，我们会更新本页面并修改上方的生效日期；如有重大变更，我们会在本站或 App 的更新说明中提示。
