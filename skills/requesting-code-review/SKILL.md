# Requesting Code Review

1. Summarize intent (1–3 bullets) and risk areas.
2. List files/packages touched and why.
3. Note tests run and remaining manual checks.
4. Call out intentional non-goals and residuals.
5. Ask reviewers for specific feedback (security, contracts, UX honesty).

Keep the request short; link the plan/spec when one exists.
