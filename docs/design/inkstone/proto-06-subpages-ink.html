二 · 学习流程

04–05 · 浏览模式没有评分，只有计划复习模式才有
浏览模式 vs 计划复习模式
同一个 FlashcardStudyView 组件，两种入口走出两种不同的动作栏。从卡片「过一遍 →」进入的是浏览模式（sequence）：翻面 + 下一张/结束浏览 + 「标记需再看」，完全没有评分按钮。从工具条「待复习」进入的才是计划复习模式（scheduled）：翻面后出现 Again/Hard/Good/Easy 四键评分。设计文档一句话「提问面→揭示→评分→回合完成」只描述了后一种，容易让人误以为所有学习路径都有评分。

六 · 宠物浮窗

14–16 · 独立系统窗口，状态枚举与文档不同
独立透明系统窗口
这不是应用内浮层——是 Tauri 层面独立的透明、无边框、置顶、跳过任务栏的 OS 窗口，加载一份完全独立的前端入口（不复用主应用模块图，避免为了一个精灵启动第二份完整 Desktop）。它没有自己的 Host 连接，靠跨窗口事件向主窗口要快照。默认开启，本地存了「false」才会隐藏。设置里显示为「显示桌面宠物」开关，位置在通用与外观页的伴侣子标签——如实呈现：文档提到的独立 pets-page.tsx 是孤儿文件，没被注册。
独立 Tauri 窗口transparent+alwaysOnTop跨窗口事件通信，无 Host 连接
七态精灵（非文档写的五态）
修正：文档写的「sleeping/idle/thinking/celebrating/error」五态与代码枚举不符——真实状态是 idle/running/waiting/failed/waving/jumping/review 七态。没有 sleeping，没有 celebrating；"thinking"只是气泡文字，精灵姿态本身在思考和运行工具时都是同一个 running；waving/jumping 是空闲时随机触发的小动作，不是稳定状态；review 是完成子代理/计划复审后的姿态，是最接近"庆祝"的东西但命名不同。
idlerunningwaitingfailedwavingjumpingreview sleeping（不存在）celebrating（不存在）
气泡：状态芯片，非消息预览
气泡在真正空闲时完全隐藏，不常驻。内容是紧凑的两层结构：一个短状态标签（思考中/运行中/等待确认/失败/完成/停止中/准备中）+ 一行标题（如"运行 read_file"）+ 可选的细节行（裁剪到 80 字符，路径类文本从末尾裁）。源码注释特别强调：不像聊天区的落地闪念语轮播，气泡必须实时反映当下正在发生的事，不做氛围性轮播。
