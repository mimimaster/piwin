密集的探索调用（如连读 5 个文件、多次 grep）若平铺在时间线上会造成严重的信噪比下降。Inkstone 的对策是「批次胶囊（Batch Capsule）」：在主链上折叠为单行概览，展开后呈递进式子轨（Sub-stream）。而对于失败命令，绝不能直接 throw 崩掉界面，而是通过朱红警戒态精准呈现退出码与堆栈关键行，将报错作为工具产物喂回模型自我修复。

自愈修正状态机的流转闭环如下：

agent_self_healing.mermaid·Mermaid 
graph TD
    Start([用户提问]) --> Loop[模型决策循环]
    Loop -->|产生 ToolCall| Parse{参数校验与反序列化}
    Parse -->|校验成功| Exec[执行本地工具]
    Parse -->|解析异常| ErrMsg[构造自愈提示消息]
    ErrMsg -->|作为 Tool 消息入栈| Loop
    Exec -->|工具执行产物入栈| Loop
    Loop -->|无 ToolCall| Done([输出最终答复])

该机制使得 Agent 对复杂输出具备极佳鲁棒性，无需脆弱的外置硬解析脚本。
