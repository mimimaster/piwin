## 0. 原型怎么看

- 顶栏：面（纸 / 墨）· 状态（就绪 / 运行中 / 等待批准，只作用于第九节「实时」）· 批注列（自动 = stage ≥ 1080px 才出现 / 开 = 强制 / 关）· 标注（右缘 ①–㉖ 编号开关）。
- 左栏是 26 块的索引，点击跳到对应块（24、25 会顺带切到「等待批准 / 运行中」）；页脚是墨线节点图例。
- 等待批准时 `Enter` 盖印允许一次、`Esc` 拒绝；点工作折叠头 / 探索胶囊 / 装配胶囊 / 可展开的工具行可折叠；点知识卡片翻转；差异卡「接受 / 拒绝」落定为文字。
- 原型把互斥状态并排放（如计划卡「执行中」与计划执行门同屏）以便对照；产品内不会同时出现。

## 3. 颜色速查（一种颜色只说一件事）

- 灯（运行）：折叠头灯点、`.tr.last` 节点、定位器、介入消息左线、生成进度条、光标。
- 朱（等你 / 你可以）：朱方节点、门的左线与印、就地编辑描边、主按钮（发送新版本 / 接受 / 采用 / 重试）、推荐项徽标、历史刻度选中。
- 松（成）：完成节点、已接受 / 已采用、任务勾、diff 新增行洗。
- 绛（坏）：失败节点与动词、错误卡、拒绝、破坏性风险、diff 删除行洗。
- 青（后台）：子代理节点、卡左线、名称、子会话墨线。
- 赭（非阻塞提醒）：Artifact 拦截徽标、`M` 修改标记。

## 5. 实施切片建议（供增量 7 汇总）

1. token 与基础件：`styles/`（tokens、`.thread / .node`、`.tr`、`.seal`）— 只换类名与变量，无行为变化。
2. 转录行：`tool-call-card.tsx` / `tool-batch-capsule.tsx` / `explore-flow-capsule.tsx` 换皮，逻辑不动。
3. 门：`gate-card.tsx` + `permission-bar.tsx` 合并展示；`onPermission` 四种调用保持。
4. 批注列：`conversation-message-header.tsx` 拆出 marginalia 渲染，容器查询驻 `region-transcript.css`。
5. 卡片：plan / walkthrough / subagent / candidate / citation / gen / flashcard / compaction / error 逐个换皮。
6. 文案：§4「文案」四项。
