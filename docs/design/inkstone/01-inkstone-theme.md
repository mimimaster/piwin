# Inkstone（砚）· 主题规范 v0（增量 0）

> 适用范围：`00-scope-inventory.md` 全部 UI 块。本文件是 token 与规则的唯一来源；`proto-00-shell.html` 是它的可视化。
> v0 = 提案。负责人确认 `README.md §6` 后升为 v1，并写 ADR（修订 ADR 0061 Deck）。

## 1. 立意

**一张纸、一块砚、一盏灯、一方印。**

piwin 已经有"深夜书案"母题（`apps/desktop/src/ink-wash-assets.ts` 的印章「砚」、"泼墨写意 · 深夜书案"），但只是空态贴画。
Inkstone 把它升级为**语义系统**：

| 词 | 含义 | 出现处 |
|---|---|---|
| 纸 / 墨 | 两张脸（浅 / 深），同等完整 | 全局 |
| 朱 | **你的手**：主操作、焦点、选中、正在等你的东西 | 新建键、发送键、许可门、待批节点 |
| 灯 | **机器的手**：Agent 正在运行——夜里案头亮灯 | 标题带、会话节点、暂停键光环、工作折叠头、子代理卡 |
| 印 | **批准**：许可门的「允」是一方朱印，Enter 盖印 | 门卡、批准后的工具行小印 |
| 砚 | **作曲器**：整张纸上唯一一块深色石板 | 作曲器 |

一句话：**文人的安静，不是戏服。** 母题只落在语义、少数签名物件与空态；99% 的界面是克制的现代工作台。

## 2. 原则

1. **转录是正文，其他一切是批注。** 元数据、工具、过程退到页边与细线上，不与正文抢宽度、抢颜色。
2. **一种颜色只说一件事。** 朱 = 等你 / 你可以；灯 = 在跑；松 = 成了；绛 = 坏了；青 = 后台 / 子代理；赭 = 非阻塞提醒（只做文字/徽标）。禁止装饰性用色。
3. **深度靠纸与光，不靠框。** 纸面：暖色柔影 + 发丝线；墨面：顶缘高光 + 暗发丝线（承 Deck）。
4. **动效即状态。** 灯呼吸 = 在跑；墨线下描 = 新工具进入；盖印 = 已批准；研墨转圈 = 准备上下文。没有为好看而动的东西。
5. **数字等宽。** token、时长、路径、行号、计数一律 tabular mono（承 Deck）。
6. **中文优先，双语等重。** 标签中文为主，路径 / 命令 / 标识符保持原文；行高与字距按 CJK 校准。

## 4. 字体与字号

- **显示 `--serif`**：`"Noto Serif SC","Songti SC","STSong","Source Han Serif SC","Source Serif 4",Georgia,serif`。只用于：空态标题、对话框 / 设置页标题、标题带会话名、印文、头像字母。字重 500–600，≥ 13.5px。
- **界面 `--sans`**：`Inter,"PingFang SC","Noto Sans SC",-apple-system,system-ui`（承 Deck，已加载）。
- **等宽 `--mono`**：`"JetBrains Mono","SF Mono",Menlo,Consolas`。代码、路径、数字、时间。
- 字号阶：`display-lg` 28/1.2 · `display-sm` 20/1.3 · `title` 15/1.4 600 · `body` 13.5/1.55 · `chrome` 12.5/1.3 500 · `micro` 10.5/1 600 tracking .08em · `mono` 11.5/1.4 · `prose` 14.5/1.72（用户可调，承 `--chat-font-size`）。

## 5. 形状、间距、尺寸

- 圆角：chip 3 · control 6 · card 8 · panel 12 · overlay 14 · **seal 4**（印近方）· pill 999。比 Deck 各收 1–2px：纸与印刷的干脆。
- 间距沿用 Deck `--s-1..--s-10`（2/4/6/8/12/16/20/24/32/40）；控件高度 24/28/32/38。
- 外壳：`--inset` 8（Deck 7）· 标题带 36 · 侧栏 236（200–420 可拖）· 检视器 304（240–720）· 正文 measure 720（用户可调 640–840）· 页边批注列 160。

## 6. 层级与纹理

- 纸面三级柔影（见 §3）；墨面承 Deck rim-light。同级卡片并列，**禁止卡中卡**。
- 纸面纹理：仅 stage 叠 2–4% fractal noise（multiply）；墨面 screen 混合、更淡。控件上不加纹理。
- 石板顶缘 1px 高光线；运行时变灯色并缓慢横移（§7 灯沿）。

## 7. 动效词汇

| 名字 | 时长 / 曲线 | 用途 |
|---|---|---|
| 呼吸 breath | 2.4s ease-in-out 循环，全局同相 | 所有"在跑"的灯点、暂停键光环 |
| 下描 draw | 240ms ease-out | 新工具行进入：墨线段自上向下描出，节点后到 |
| 盖印 stamp | 160ms spring：scale .88 → 1，−4° 回正；印迹 0 → .92 | 允许；完成后工具行末保留 17px 小印 |
| 研墨 grind | 1.4s linear 单弧旋转 | 准备上下文 / 正在思考（替代 shimmer） |
| 灯沿 sheen | 4.8s linear 渐变横移 | 运行中的石板顶缘 |
| 折叠 fold | 240ms ease-out 高度 | 工作折叠、分区 |
| t-1..t-4 | 90 / 150 / 240 / 380ms | 悬停 / 弹层 / 抽屉 / 面板（承 Deck） |

`prefers-reduced-motion`：呼吸与灯沿改为静态实色；下描 / 盖印改为淡入。

## 8. 签名物件

1. **印（Seal）** — 许可门。36×36 朱底、白色内框双线、宋体「允」；「否」为墨线空印。`Enter` 盖印允许、`Esc` 拒绝，`允 · 本会话 / 允 · 项目` 收进下拉。批准后工具行末尾留小印。语义与 ADR 0019 一致，只换皮与手感。
2. **灯（Lamp）** — 运行。7px 圆点 + 8px 柔光，呼吸。位置：标题带会话名前、侧栏当前会话节点、作曲器暂停键、工作折叠头、子代理卡。
3. **砚（Slab）** — 作曲器。纸面上唯一深色物件；墨面里比 void 更深一档。发送键朱色圆钮；运行时顶缘灯沿。
4. **墨线（Thread）** — 过程。侧栏项目内会话、转录工具链共用同一根 1–1.5px 竖线 + 节点语言：空心 = 待 · 松 = 成 · 灯 = 跑 · 朱方 = 等你 · 青 = 后台。
5. **批注（Marginalia）** — 元数据。stage ≥ 1080px 时，"谁 · 何时 · 多少 token"进入左页边 160px 列并随滚动吸顶；更窄时回到行内头部。正文 measure 与作曲器始终对齐。
6. **案头（Shelf）** — 侧栏页脚。资料库 / 知识卡片 / 设置 三格 + Host 状态点。顶部只剩一个搜索 / 跳转框和一颗朱色「新建」。不恢复 nav rail（尊重 `8324d403`）。

## 9. 布局契约（相对 Deck 的变化）

- 标题带 36px 独立行（Deck：32px 覆盖层）；三张面板在其下以 `--inset` 浮在 void 上；红绿灯留白 84px。
- 侧栏顶部 4 行动作 → 1 行（搜索 + 新建）；资料库 / 知识卡片 / 设置下沉到案头页脚。
- 分区顺序：置顶 → 项目（文件夹）→ 对话；文件夹内会话走墨线。
- 转录：条件出现的左页边批注列；用户消息 = 纸卡（s3）；助手 = 裸文档流；工作折叠 = 墨线工具链；许可门 = 印。
- 作曲器：石板浮岛；上方可叠"已排队"纸条；提示行在其下。
- 检视器：文字页签 + 徽标，头部 + / 最大化 / 关闭；宽度与折叠规则承 Deck。
- 紧凑（< 1040）：检视器隐藏（标题带可唤出为覆盖层）；侧栏成抽屉（承 Deck）。

## 10. 组件规则速览

- 按钮：ghost 默认；主按钮 = 朱底 + on-zhu；危险 = 绛字 ghost，确认时绛底。
- 芯片：r-chip 3，mono 计数；`@path` 引用芯片在纸卡与石板上各一套底色。
- 卡片：s3 + sh1；同级并列。
- 工具行：28px 高，节点在墨线上，**动词加粗** + `code` 参数 + 右侧 mono 元数据；悬停浮 s3。
- 代码块：`--code` 底 + 头行（语言 · 路径 · 复制）。
- 弹层 / 菜单：s4 + sh3，r-overlay 14；标题宋体 display-sm。
- 横幅：纸条（s3，26–28px），文字 + 两个动作；不用彩底。
- 吐司：右下，s4，左缘 3px 语义色线（松 / 赭 / 绛 / 青）。

## 12. 明确不做

- 不在控件、按钮、卡片上画笔触、宣纸纹或印章；水墨插画只留空态（`ink-wash-empty-vignette`）与连接墙。
- 不用毛玻璃 / 透明叠层（承 Deck 的 Ember Glass 否决）。
- 不恢复导航 rail；不新增第二个强调色。
- 不改变任何交互契约：键盘（Enter / ⌘Enter / ⇧Enter / Esc / IME）、运行语义（排队 / 介入 / 暂停）、权限门的三种允许、多窗格快捷键。
