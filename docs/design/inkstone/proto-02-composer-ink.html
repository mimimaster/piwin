一 · 状态机

01–03 · 石板是唯一活体展台，顶栏「状态」驱动
石板七态
石板（composer-card.tsx + composer-run-actions.tsx）在同一块深色物件里流转七种状态；下方展台随顶栏「状态」实时变化，其余块保持静态。
空闲 — 占位符，主键为发送（禁用，无内容） 草稿 — 有文本，主键为发送 流式 — 主键为暂停，石板顶缘灯沿横移 已排队 — 流式中已有草稿，主键变「加入后续队列」 暂停中 — 主键禁用，文案「正在暂停…」 已暂停 — 无草稿时主键变「继续运行」 队列编辑 — 横幅置顶，主键变「保存修改」（松色）
主动作圆钮四态速查
同一枚圆钮承载全部主动作（ComposerActionSlot）：发送 → 暂停 → 继续；有草稿时优先排队；仅失败附件时变重试。
发送idle / draft / paused+草稿 — Enter
暂停streaming 且无草稿 — 灯色光环呼吸
加入后续队列streaming 且有草稿 — Enter 排队，⌘Enter 仍走转向
继续运行paused 且无草稿 — 从检查点继续
重试附件仅剩失败附件、无可发送文本时
键盘契约速查
承 Deck 的键盘语义，只换皮不换契约（composer-card.tsx IME 组合守卫 + lastCompositionEndRef 100ms 去抖窗口）。
按键空闲 / 草稿流式队列编辑
Enter发送加入后续队列（有草稿）保存回队列
⇧Enter换行换行换行
⌘Enter—转向当前任务（绕开 IME 守卫）—
Esc关闭 @ / / 菜单关闭菜单取消编辑，消息留在队列原状
IME 组合中抑制发送；组合结束 100ms 内仍抑制同左；⌘Enter 不受影响同左
