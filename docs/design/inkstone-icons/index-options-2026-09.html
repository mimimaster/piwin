使用建议：
· 生图方案中 砚台·俯视 / 毛笔·垂滴 最点题；印章·π 最有品牌辨识度（π = piwin）。
· SVG 方案中 01 / 02 最点题；09 / 10 印章感最强；15 最强调对话属性。
· 混合玩法：取生图做底板质感，再叠加手工 SVG 图形（如 seal-pi 底 + SVG π 字），可得到更精致的成品。
· SVG 均为单色剪影逻辑，把前景色换成 currentColor 即可自动适配亮/暗模式。
· 需要 PNG 时按 1024×1024 导出；SVG 复制源码后可存入 apps/desktop/src-tauri/icons/。
