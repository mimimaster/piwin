Design Spec v2.3 · 2026-07-27 · piwin desktop

壳层重设计:静默工作台

最终形态:无硬边界的一体工作台 + 可收起的右侧工作面板。 左右栏与顶栏同色同透、不画明显分割线;对话贴顶排列。 工作面板(Changes / 终端 / …)仅在顶栏右上角面板按钮展开时出现。 对话区保持干净——不做右缘消息刻度/导航轨,长会话定位留给后续大纲类能力另议。

布局 一体色场 · 右栏可收起 右栏触发 顶栏右上角 对话流 置灰流式 + 完成折叠

01 · 设计原则

四条原则,贯穿所有改动

P1

无框优先

图标按钮默认透明无边框,悬停浮现 6–8% 色块;边框只留给输入区和悬浮层。现有 boxed .icon-btn 全部退役。

P2

内容即界面

助手消息去掉气泡,回归文档流;面板靠背景微差与发丝线分区,不再套「盒子里的盒子」。

P3

动效即状态

动画只在状态变化处出现:思考 shimmer、面板滑入、消息进场、运行脉冲。120–260ms,一套缓动,全局尊重 reduced-motion。

P4

一套图标语言

24 网格 / 1.6 描边 / 圆头圆角,尺寸走 token。清除 8 种描边宽度、文字字符图标(× ★ ⚙)与 emoji 混用。

02 · 最终布局

一体色场三栏 · 工作面板可收起

视觉:左会话栏、中央对话、右侧工作面板、顶栏共用同一 graphite 底,去掉明显竖线/横线边界, 只靠内容分区(与标注一致:左右透明度一致,上方也一样)。 工作面板:顶栏右上角面板按钮展开/收起整栏(与 Cursor 等 IDE 一致); 收起后整列消失,对话吃满宽度。上下文栏只保留会话标题 / 作用域 / 运行态,不再塞面板开关。 消息从顶部开始排布,不垂直居中。对话区右缘不做消息刻度条,保持静默。

07 · 落地

四个工作包,守住现有护栏

实施顺序

  • W1 基座 — 图标库重绘 + 动效 token + ghost 按钮体系(ui-kit)
  • W2 布局 — 一体色场、右面板整栏展开/收起 + 目录钻入、composer 悬浮化
  • W3 对话流 — 去气泡、thinking 流式折叠、工具行、等待态
  • W4 收尾 — reduced-motion 全局策略、视觉基线重生成、testid 迁移

护栏(不动的东西)

  • host / reducer / 持久化逻辑 零改动
  • data-layout 单一布局权威与响应式断点保持
  • 新 CSS 不使用 !important
  • testid 若改名,同 commit 迁移测试断言
  • 8 张 darwin 视觉基线在 W4 一次性重生成
