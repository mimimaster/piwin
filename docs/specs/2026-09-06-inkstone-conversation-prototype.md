# Inkstone · Conversation 会话原型 09

日期：2026-09-06。状态：设计提案 / 可交互 HTML；尚未接入 Desktop 或 Host。

## 目标与参考

重新设计 Conversation 下的会话阅读与交互，重点解决字体角色混用、信息权重接近、过程信息干扰正文，以及消息操作缺少层次的问题。

主要视觉参考为 `docs/design/inkstone/proto-00-shell-original.html`，结合 `proto-01-transcript.html`、`proto-02-composer.html`、`proto-03-navigation.html`。参考文件作为视觉与行为研究材料；本提案不修改这些文件，也不改变已发布产品决策。

入口：`docs/design/inkstone/proto-09-conversation.html`。直接打开 HTML 即可运行，依赖同目录的 CSS / JS，无外部字体、图片、CDN、模型或网络请求。

## 视觉与排版

- 复用 `shell-foundation.css` 的纸 / 墨色阶、朱红、松绿、暖色阴影；朱红用于主动作与需要处理的事项，完成用松绿，运行用暖金。
- 字体分工：标题为 Songti / Noto Serif SC 系列；控件、中文正文为 Inter / PingFang SC / 系统无衬线；文件名、代码、快捷键及计量为 JetBrains Mono / SF Mono / Menlo。
- 正文默认 15px，行高 1.85；面板中可预览 14 / 15 / 16px。标题 22px、正文小标题 16px、控件 12.5–13px、辅助信息 11–12px。正文不使用宋体或等宽字体。
- 阅读宽度默认 720px，可试 640 / 720 / 800px。消息、过程、输入框共用同一条左对齐线，不预留空头像栏。
- 用户提问为浅纸卡；助手正文直接落在纸面。过程用折叠行，输出文件用小型文档卡，避免每段文字套一层容器。
- 侧栏行高与尾部操作区固定，悬停时不挤压标题；同时支持键盘聚焦和触屏。当前项以纸面抬升和细朱线标识。

## 页面结构

左侧为 Conversation / 项目会话及搜索；中央为会话标题、消息流、固定输入区；右侧为可收起的目录 / 资料 / 排版面板。顶部细条是原型控制区，明确标识演示内容，不属于正式产品。

宽屏同时显示三栏；中等宽度把辅助面板变成抽屉；窄屏侧栏也变成抽屉。关闭抽屉后焦点回到触发按钮；Esc 关闭浮层。正文不会因文件名或代码横向撑破页面。

## 交互约定

| 场景 | 设计行为 |
| --- | --- |
| 阅读 | 助手正文默认展开；工作过程默认收起；时间与模型降为辅助信息 |
| 工作过程 | 一条摘要展示完成的工作、工具数量、耗时；展开为连续墨线，各步骤可查看输出 |
| 消息操作 | 悬停或键盘焦点进入后显示复制 / 编辑 / 分支 / 重试；操作占位稳定 |
| 编辑提问 | 卡片内编辑；取消返回原文；保存时建立分支，保留原会话 |
| 分支 | 从当前回复创建新会话，展示来源入口；可返回原会话 |
| 重试回复 | 保留已有版本；生成后显示版本切换，原提问不重复追加 |
| 运行 | 工作摘要、侧栏状态点与输入区状态一致；空输入时主按钮暂停 |
| 运行中发送 | Enter 排队；⌘/Ctrl Enter 介入；排队消息可取回编辑或撤回 |
| 暂停 | 空输入时继续当前步骤；有输入时发送新轮次，不暗中恢复旧任务 |
| 待确认 | 在请求发生处展示作用范围与文件；允许一次 / 暂不允许为明确按钮 |
| 异常 | 原位置显示错误与重试；保留提问、草稿和附件 |
| 附件 / 引用 | 选择附件只在本地演示名称；引用材料可打开右侧资料面板 |
| 切换会话 | 每个会话分别保留草稿、附件、排队内容、消息与阅读位置 |
| 长会话 | 向上阅读不被流式结果拉走；底部提供回到最新入口 |
| 输入法 | 中文组合输入期间 Enter 不发送；Shift Enter 换行 |
| 空白会话 | 简短开场与三条可点击的示例提问，输入后沿用正常消息布局 |

## 原型覆盖与边界

包含普通阅读、过程展开、运行与排队、等待确认、暂停、连接异常、空白会话、编辑分支、版本切换、资料查看、字体与宽度调节、纸墨主题及窄屏抽屉。

所有回复、工具输出、权限结果和耗时均为本地演示数据；不会调用模型、运行命令、写入项目文件或授予真实权限。附件不会上传；页面刷新后会话演示状态重置。字体使用系统已安装字体，缺失时沿声明顺序回退，不下载字库。

实现采用普通 HTML 原型，与现有原型的运行方式一致。若设计通过并接入 Desktop，按钮、菜单、对话框等必须使用 `@piwin/ui-kit`，会话与运行状态由 Host 契约驱动；本原型的内存状态不能移植为产品权威。
