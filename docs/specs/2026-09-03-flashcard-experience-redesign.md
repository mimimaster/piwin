# 闪卡体验重构：一个家，三个动词

日期：2026-09-03  
状态：**产品方向已由 owner 确认；P0 实施中。** 本文修订 [2026-08-30 复习台执行规格](./2026-08-30-flashcard-review-workbench-spec.md) 的 §5.3 / §6.1（整卡点击翻面、去掉暂停按钮），其余 Host 契约、撕卡契约、唯一 CardStore、ADR 0066 数据模型不变。  
权威：产品 owner（AGENTS §0.1）。  
范围：Desktop 闪卡家（卡库 / 出卡 / 复习台）表层产品模型；Mobile 同步 P0 交互；不改 Host 命令。

## 1. owner 的三个不满与根因

| 不满 | 代码根因 |
|---|---|
| 复习时卡片单独占满，还得点按钮才翻面 | 8-30 规格 §6.1 为划词让路，明文“点击正文不翻面”；`FlashcardFace` 只把 `onFlip` 挂在顶部 meta 条 |
| 闪卡预览观看不灵活 | 复习台只有“一张卡一条流水线”一种形态；看不见整套、不能跳、不能对照；卡库瓷片不能就地翻 |
| RAG 出卡流程藏起来、不直观 | 「出卡」是整页跳转进入 7 阶段向导，出完再跳回；来源在闪卡家里不是一等公民 |
| 整体模糊 | UI 词汇暴露了 sequence / scheduled / 需再看 / 巩固子集 / 暂停 / 接管 / 到期题 vs 新题 等工程概念；仓库残留三套卡面（`FlashcardsPanel`、`tear-deck.tsx`、聊天 `fc-quiet-*`） |

底层（Host 持有轮次、幂等操作日志、`ReviewState.revision`、撕卡动效）保留，问题全在表层。

## 2. 目标信息架构

```text
闪卡（侧栏唯一入口，整页）
├─ 来源栏（左侧常驻，像 Finder 侧栏）      ← 原「出卡」向导降级为面板
│    文件夹 A   已入库 · 出过 2 套 · [再出一套]
│    工作空间   未入库          · [入库]
│    + 添加资料
├─ 卡库（主区，默认）
│    一套 / 一张 瓷片；瓷片可就地翻面预览（不进复习、不计进度）
│    生成中的套是“正在出卡 3/8”的活瓷片，卡边生成边落进来
└─ 学（顶部主按钮 + 瓷片动作）
     「今日复习 · 到期 N」   ← Host scheduled
     瓷片 →「过一遍」        ← Host sequence
```

三个动词：**来源 → 卡 → 学**。出卡不再“去别处”，进度不再是结果页。

## 3. 复习台交互原则（修订 8-30 规格）

| 8-30 规格 | 2026-09-03 修订 |
|---|---|
| §5.3 / §6.1：点击正文不翻面，只有按钮和 Space | **点卡任何位置翻面。** 点 = pointerdown 到 click 位移小于阈值且松开时卡内无选区；拖选文字不翻；点击卡内链接 / 按钮 / 输入控件不翻。划词伴学保留 |
| 「提问 / 解答」是主按钮 | 翻面按钮降级为次要（带 Space 提示）；**主按钮只剩「下一张」/ 四档评分** |
| scheduled 翻面后评分条才出现 | **评分条常驻占位**：未翻面灰化不可点，翻面后点亮；布局不跳 |
| §6.1：复习台有显式「暂停 / 继续」，暂停遮住题面 | **去掉暂停按钮。** 返回即保存（Host `pause`），再次进入自动 `resume`；Host `flashcards/study/pause|resume` 命令保留供 CLI / 离开路径使用。Mobile 切后台的题面遮挡是隐私行为，与用户可见的“暂停”无关，保留 |

不变：撕卡契约（§5.1 / §5.2）、Host 提交在前动画在后、`animationend` 不发请求、幂等键、撤销语义、卡面视觉基线。

### 3.1 视图模式（P1，设备本地显示状态，不进 Host）

1. **专注**：现有单卡 + 撕卡，默认。
2. **叠卡**：露出下层卡边 + 右侧本套缩略条，可跳到任意张（第一版仅 sequence）。
3. **总览**：整套铺成小网格，每张可原地翻面；「从这里开始」进入专注。

快照已有 `entries` / `counts`，不需要新契约。

### 3.2 卡库瓷片就地翻面（P1）

瓷片即迷你闪卡：点一下显示答案，再点翻回，不进复习、不写任何进度；瓷片角上「过一遍 →」才进复习台。

### 3.3 用户词汇

UI 只出现：**一套 / 一张 / 卡组 / 过一遍 / 今日复习 / 标记再看 / 撤销**。`sequence` / `scheduled` / entry / revision / claim 只留在代码与契约里。“在另一设备接管”只在真实冲突时出现。

## 4. 出卡流程可视化（P2）

7 阶段向导收成常驻来源面板里的三步条：

```text
① 选资料 ──→ ② 入库（可选，进度环） ──→ ③ 出卡（主题可选）
```

- 每个来源一行：未入库 / 入库中 / 已入库 N 文件 / 出过 M 套。
- 「出卡」不跳页：卡库出现“正在出卡”活瓷片，完成后变成普通一套带「过一遍」。
- 失败 / 降级用 `Notice` 就地提示；`KnowledgeResultView` 终点页删除。
- 「忘掉此文件夹的卡」进来源行菜单，需确认。

复用 `useFlashcardsProduce` 与 `doccards/*` 命令；`ProduceStage` 从页改为面板。

## 7. P0 验收

- [ ] 点卡片正文任意位置翻面；拖选一段文字松开不翻面；选区存在时再点一次（清空选区的那一下）不翻面。
- [ ] 点击卡内链接 / 按钮不翻面。
- [ ] Space 仍翻面；1–4 仅答案面有效；原生按钮上的 Space / Enter 不被双重处理。
- [ ] scheduled 未翻面时评分条可见但禁用；翻面后可点；连点只评一次。
- [ ] sequence 主按钮是「下一张」/「结束浏览」；翻面按钮为次要。
- [ ] 复习台没有暂停 / 继续按钮；返回后再进入同一套，回到同一张同一面，无需额外操作。
- [ ] 另一设备 claim 一个已暂停轮次后可直接学习。
- [ ] Mobile 切后台题面仍遮挡，回前台恢复。
