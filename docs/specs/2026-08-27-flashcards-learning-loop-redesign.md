# 闪卡产品规格

> **状态：** 产品口径已定（2026-08-27）  
> **范围：** Desktop 闪卡  
> **权威：** 产品 owner

piwin 是 coding-agent shell。闪卡是 Agent 从资料里抽出的记忆卡片。**我们负责产卡；用户自己管卡。**

---

## 1. 一句话

侧栏 **「闪卡」** 是唯一的家——像 **图片页、视频页**：点进去是整页跳转（侧栏消失），先看见已经有的卡；聊天里出的卡也进这个家。

---

## 2. 闭环

```text
资料（文件夹 / 工作空间 → 向量库；向量库 chunk；模型知识；web search）
  → 出卡（RAG 两段式：知识点 → 有序卡）
  → 增量写入 CardStore（~/.piwin/flashcards/）
  → 闪卡页平铺展示、用户增删改、点开单卡翻面 / 一套撕到下一张
```

每次出卡往家里 **加**。不满意 **删一张或删整套**，再出。文件夹 / 工作空间只表示资料从哪来；卡落在同一个家里，用户自己管留哪些。

---

## 3. 词表

| 词 | 含义 |
|----|------|
| **家** | 侧栏「闪卡」。点进去是整页跳转（侧栏消失），先展示已有卡；聊天出的卡也在这里 |
| **资料** | 进向量库前的来源：文件夹、工作空间、web search 结果等 |
| **向量库** | doc-rag 索引（Parse / Chunk / FTS + 可选向量）。卡的真值在 CardStore markdown |
| **一张** | 独立闪卡，无同套下一张 |
| **一套** | 一次出卡产生的多张有关系卡：`sequenceId`、`position`、`relationFromPrevious` |
| **出卡** | 资料经 RAG 产出一张或一套，写入 CardStore |
| **增** | 手写新建，或任一出卡路径 |
| **删** | 删一张，或删整套 |
| **改** | 删这张 / 这套，再出 |
| **平铺** | 闪卡页默认：所有卡像图库铺开 |
| **撕** | 一套内：点掉当前张，同一窗口露出下一张 |

## 4. 一个家（侧栏「闪卡」）

### 4.1 与图片 / 视频同一范式

| | 图片 | 视频 | 闪卡 |
|---|------|------|------|
| 侧栏入口 | 图片 | 视频 | 闪卡 |
| 点进去 | 整页跳转，侧栏消失，已生成的图 | 整页跳转，侧栏消失，已生成的视频 | 整页跳转，侧栏消失，已有的卡 |
| 聊天产出 | 进图库 | 进视频库 | 进 CardStore，此处可见 |
| 关掉页 | 回会话 | 回会话 | 回会话 |

### 4.2 闪卡页功能

1. **展示（默认）**  
   平铺所有卡。单张：点开翻面。一套：平铺上像一张（叠卡只露顶）；点开后在 **同一窗口撕** 到下一张，直到没有下一张。

2. **管理**  
   增：手动新建或任一出卡路径。删：一张或整套。改：删了再出。

3. **产卡**  
   本页进入：**选文件夹 / 挂工作空间 → 勾文件 → 入库 → 进度 → 出卡**。  
   保留原知识中心整条 RAG 产卡能力：选文件夹、用当前工作空间、扫描勾选、入库与取消、出卡与进度、打开来源、忘掉文件夹下卡（需确认）。

4. **出口**  
   关掉闪卡页回会话。

### 4.3 没有第二扇门

侧栏底下不再放「知识中心」。加号菜单、`/knowledge` `/doccards` `/wiki` `/flashcards` 都进这一页。入库 + 出卡能力在闪卡页的产卡轨，设置里的「知识库与向量」只配 embedding，不是产品入口。

---

## 5. 出卡

### 5.1 两条路径，同一 CardStore

| 发起 | 操作 | 产出 | 落点 |
|------|------|------|------|
| 闪卡页 | 文件夹 / 工作空间 → 入库 → 生成 | 通常一套 | CardStore → 闪卡页平铺 |
| 聊天 | 划词、斜杠、打字要求生成 | 一张或一套 | 当场展示 + 写入 CardStore |

### 5.2 聊天主动出卡

- **划词**：选中文字 → 生成闪卡  
- **斜杠**：`/flashcards`、doccards 相关命令  
- **打字**：自然语言要求生成  

出 **一套** 时：消息内固定区域嵌卡，**一张一张撕**。出完写入 CardStore，闪卡页可见同一份数据。

### 5.3 RAG 两段式（`packages/doc-rag`，`v2-two-stage`）

出卡资料统一为：向量库 chunk、模型知识、web search 结果。

1. **LLM#1** — 从 ContextPack 抽 `KnowledgePoint`（概念、陈述、类型、重要度、来源 chunk）。  
2. **LLM#2** — 按序输出闪卡：`sequenceId`、`position`、`relationFromPrevious`、`knowledgePointIds`、`sourceChunkIds`。

### 5.4 增量

每次出卡往 CardStore **追加**。用户删不要的，再触发出卡。

---

## 6. 展示与交互

### 6.1 闪卡页

- 默认平铺（网格或列表）。  
- 单张：点开翻面，关闭回平铺。  
- 一套：平铺视觉上一张；窗口内撕顶张 → 同套下一张，直至结束。

### 6.2 聊天

- 一张：单卡组件。  
- 一套：固定区域 + 撕（与闪卡页同一交互语义）。  
- 持久展示与管理在闪卡页。

### 6.3 同套下一张

同 `sequenceId`，按 `position` 排序。见 [ADR 0054](../adr/0054-flashcard-item-review-card.md)。

---

## 7. 管卡

| 操作 | 行为 |
|------|------|
| 增 | 手动新建；或任一出卡路径 |
| 删 | 删一张；或删整套（同 `sequenceId`） |
| 改 | 删这张 / 这套，再出 |

新卡写入时可去重；用户可随时删。

---

## 8. 收口：删掉什么

### 8.1 产品 / UI 删掉

| 删什么 | 改为什么 |
|--------|----------|
| 侧栏「知识中心」作为闪卡 / 出卡入口 | 入库 + 出卡并进 **闪卡页**；知识中心钮去掉或只保留与闪卡无关的设置（若有） |
| 闪卡页「闪卡记忆中心 / 今日概览 / 待复习 / Mastered / 开始复习」 | 进去 **先平铺展示卡**（对齐图片页） |
| 右栏 `FlashcardsPanel` 当第二套闪卡家 | 到期卡若有需要，从闪卡页进入；或缩成与 CardStore 同一数据源的一眼预览 |
| 知识中心出卡结果 →「打开复习会话」跳聊天 | 出完留在 **闪卡页**；聊天只做当场撕卡预览 |
| 一套卡主交互「‹ 上一张 / 下一张 ›」 | **同一窗口撕** |
| 知识中心 Wiki 搜索抽屉、`/wiki` 斜杠入口 | 删除（旧挂件） |
| 按文件夹「套 1 / 套 2」编号 UI | 删除；库内平铺 + 用户删留 |
| 以学代审、卡片「能不能用」状态、今日待刷首页 | 删除相关文案与入口 |
| 入口矩阵（五进四出）、StudySpace、三栏复习桌 | 删除方案与残留 UI |

### 8.2 文档作废

- 旧稿：`StudySpace`、入口矩阵、以学代审、每日复习仪式、`docs/superpowers/specs/2026-08-17-knowledge-center-loop-repair-design.md` 里「打开复习会话 / 到期 FSRS 右栏为主」部分 — **以本文为准**。

### 8.3 保留并迁入闪卡页

原 `KnowledgeCenterPanel` 产卡环：`scan-folder`、`index-folder`、`generate`、进度环、文件勾选、`forget-folder`、`open-source` — **能力原样保留**，Presentation 改在 `FlashcardsWorkspaceView`（或等价全屏页）。

## 11. 验收

1. 侧栏「闪卡」一点，看见所有已落盘卡（含聊天出的）。  
2. 文件夹 / 工作空间 → 向量库 → 出卡，在闪卡页可完成。  
3. 划词 / 斜杠 / 打字可出卡；出完闪卡页可见。  
4. 平铺；一套在同一窗口可撕到下一张。  
5. 可删一张 / 删一套；改 = 删了再出。
