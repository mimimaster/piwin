# 闪卡产品规格

> **状态：** 产品口径已定（2026-08-27；划词收敛 2026-08-30）。卡库 / 出卡 / 划词仍以本文为准。独立复习台以 [2026-08-30 规格](./2026-08-30-flashcard-review-workbench-spec.md) 与 [ADR 0066](../adr/0066-host-owned-flashcard-study-rounds.md) 为准（代码已在树；双端真机证据未齐，ADR 未标 Accepted）。  
> **范围：** Desktop 闪卡家（唯一 CardStore）；复习台另见 2026-08-30 规格  
> **权威：** 产品 owner  
> **执行计划：** [闪卡划词收敛与学习闭环](../plans/2026-08-30-flashcard-selection-convergence-execution-plan.md)（`docs/plans/` 按仓库策略本地/未跟踪，clone 后需自备该文件）

piwin 是 coding-agent shell。闪卡是 Agent 从资料里抽出的记忆卡片。**我们负责产卡；用户自己管卡。**

本文不改 CardStore / review 的存储位置，也不改 `sequenceId` / `position` 展示顺序语义（见 [ADR 0018](../adr/0018-notes-flashcards-local-rag.md)、[ADR 0054](../adr/0054-flashcard-item-review-card.md)）。**唯一卡库**与原撕卡要求仍有效。Host 拥有的学习轮次、operation 日志与 `ReviewState.revision` 见 [ADR 0066](../adr/0066-host-owned-flashcard-study-rounds.md)，不是第二套卡库。

原「没有独立复习台 / 库内点开走临时 TearDeck 浏览即学习闭环」的结论 **作废**。点单张或一套进入 Host 复习台（`sequence`）；卡库「待复习」进入 `scheduled`。浏览不再是仅本地 `index` / `revealed` 的临时叠卡。

---

## 1. 一句话

侧栏 **「闪卡」** 是唯一的家——像 **图片页、视频页**：点进去是整页跳转（侧栏消失），先看见已经有的卡；聊天里出的卡也进这个家。

---

## 2. 闭环

```text
资料（文件夹 / 工作空间 → 向量库；向量库 chunk；模型知识；web search）
  → 出卡（RAG 两段式：知识点 → 有序卡）
  → 增量写入 CardStore（~/.piwin/flashcards/）
  → 闪卡页平铺展示、用户增删改
  → 点单张 / 一套进入 Host 复习台（撕卡契约不变；见 2026-08-30 规格）
```

每次出卡往家里 **加**。不满意 **删一张或删整套**，再出。文件夹 / 工作空间只表示资料从哪来；卡落在同一个家里，用户自己管留哪些。

---

## 3. 词表

| 词 | 含义 |
|----|------|
| **家** | 侧栏「闪卡」。点进去是整页跳转（侧栏消失），先展示已有卡；聊天出的卡也在这里 |
| **资料** | 进向量库前的来源：文件夹、工作空间、web search 结果等 |
| **向量库** | doc-rag 索引（Parse / Chunk / FTS + 可选向量）。卡的真值在 CardStore markdown |
| **一张** | 独立闪卡，无同套下一张 |
| **一套** | 一次出卡产生的多张有关系卡：`sequenceId`、`position`、`relationFromPrevious` |
| **出卡** | 资料经 RAG 产出一张或一套，写入 CardStore |
| **增** | 手写新建，或任一出卡路径 |
| **删** | 删一张，或删整套 |
| **改** | 删这张 / 这套，再出 |
| **平铺** | 闪卡页默认：所有卡像图库铺开 |
| **撕** | **动画语义**：一套内顶张被移走、露出下一张的视觉效果。用户可见按钮文案是 **「下一张」**，不是「撕掉」 |
| **结束浏览** | 单张或一套的最后一张导航按钮；完成页写 **「已浏览 N 张」**，不写「掌握」 |

## 4. 一个家（侧栏「闪卡」）

### 4.1 与图片 / 视频同一范式

| | 图片 | 视频 | 闪卡 |
|---|------|------|------|
| 侧栏入口 | 图片 | 视频 | 闪卡 |
| 点进去 | 整页跳转，侧栏消失，已生成的图 | 整页跳转，侧栏消失，已生成的视频 | 整页跳转，侧栏消失，已有的卡 |
| 聊天产出 | 进图库 | 进视频库 | 进 CardStore，此处可见 |
| 关掉页 | 回会话 | 回会话 | 回会话 |

### 4.2 闪卡页功能

1. **展示（默认）**  
   平铺所有卡。单张 / 一套：平铺上像一张（叠卡只露顶）。点开进入 **Host 复习台** 的顺序模式（`sequence`），不是仅本地的临时 TearDeck 浏览。撕卡动画、按钮「下一张」/「结束浏览」、完成页「已浏览 N 张」仍是交互契约（见 [2026-08-30 规格](./2026-08-30-flashcard-review-workbench-spec.md)）。卡库可另开「待复习」（`scheduled`）；这不是把图库首页改回学习仪表盘。

2. **管理**  
   增：手动新建或任一出卡路径。删：一张或整套。改：删了再出。

3. **产卡**  
   本页进入：**选文件夹 / 挂工作空间 → 勾文件 → 入库 → 进度 → 出卡**。  
   保留原知识中心整条 RAG 产卡能力：选文件夹、用当前工作空间、扫描勾选、入库与取消、出卡与进度、打开来源、忘掉文件夹下卡（需确认）。

4. **出口**  
   关掉闪卡页回会话。

### 4.3 没有第二扇门

侧栏底下不再放「知识中心」。加号菜单、`/knowledge` `/doccards` `/wiki` `/flashcards` 都进这一页。右栏工作台空态和 `+` 菜单不放「知识卡片」——那是会话工具面，不是闪卡入口。入库 + 出卡能力在闪卡页的产卡轨，设置里的「知识库与向量」只配 embedding，不是产品入口。

## 5. 出卡

### 5.1 两条路径，同一 CardStore

| 发起 | 操作 | 产出 | 落点 |
|------|------|------|------|
| 闪卡页 | 文件夹 / 工作空间 → 入库 → 生成 | 通常一套 | CardStore → 闪卡页平铺 |
| 聊天 / 文档划词 | 右键「生成闪卡」 | **恰好一张**原子卡 | 当前会话展示同一张卡 + 写入 CardStore → 闪卡页可见 |
| 聊天 | 斜杠、打字要求生成 | 一张或一套 | 当场展示 + 写入 CardStore |

### 5.2 聊天 / 文档划词出卡（外部选区）

```text
聊天 / 文档中划词
  → 生成闪卡
  → Agent 创建一张原子卡
  → 当前会话展示同一张卡
  → CardStore 落盘
  → 闪卡页可见
```

约束：

- 外部划词主动作是 **生成闪卡**，结果是 **恰好一张**卡（原子问题，答案最多两句话，必须走现有 `flashcard_create` / CardStore）。
- 仅划选文本不发请求、不写卡；动作是显式意图。
- 不把提示词复制到剪贴板冒充完成。

### 5.3 聊天其它出卡

- **斜杠**：`/flashcards`、doccards 相关命令  
- **打字**：自然语言要求生成  

出 **一套** 时：消息内固定区域嵌卡，**一张一张**用撕卡动画进入下一张。出完写入 CardStore，闪卡页可见同一份数据。

### 5.4 RAG 两段式（`packages/doc-rag`，`v2-two-stage`）

出卡资料统一为：向量库 chunk、模型知识、web search 结果。

1. **LLM#1** — 从 ContextPack 抽 `KnowledgePoint`（概念、陈述、类型、重要度、来源 chunk）。  
2. **LLM#2** — 按序输出闪卡：`sequenceId`、`position`、`relationFromPrevious`、`knowledgePointIds`、`sourceChunkIds`。

### 5.5 增量

每次出卡往 CardStore **追加**。用户删不要的，再触发出卡。

## 6. 展示与交互

### 6.1 闪卡页

- 默认平铺（网格或列表）。  
- 单张或一套：点开进入复习台顺序模式；撕卡动画 → **下一张**，直至结束。按钮文案是「下一张」；最后一张是 **「结束浏览」**；完成页写「已浏览 N 张」。真正删除只叫「删这张 / 删整套」，危险色不画在导航按钮上。  
- 动效参考仍是现有 `TearDeck` / `fcws-tear-off`（200ms、位移+旋转+淡出），不是分页、轮播或换文字。

### 6.2 聊天

- 一张：单卡组件。  
- 一套：固定区域 + 撕卡动画导航（与闪卡页同一交互语义）。  
- 持久展示与管理在闪卡页。

### 6.3 同套下一张

同 `sequenceId`，按 `position` 排序。见 [ADR 0054](../adr/0054-flashcard-item-review-card.md)。

### 6.4 卡内划词伴学（正面提示 / 背面讲解）

```text
闪卡正面划词
  → 给我提示（不泄露答案）
  → 当前复习窗口内显示短提示

闪卡背面划词
  → 讲解
  → 当前复习窗口内显示短讲解
  → 举例 / 换个说法 / 做成新卡
```

约束：

- 卡面文字可拖选；单击文字不翻面；Space（卡片聚焦时）与显式翻面按钮才翻面。

## 7. 管卡

| 操作 | 行为 |
|------|------|
| 增 | 手动新建；或任一出卡路径 |
| 删 | 删一张；或删整套（同 `sequenceId`） |
| 改 | 删这张 / 这套，再出 |

新卡写入时可去重；用户可随时删。

## 8. 收口：删掉什么

### 8.1 产品 / UI 删掉

| 删什么 | 改为什么 |
|--------|----------|
| 侧栏「知识中心」作为闪卡 / 出卡入口 | 入库 + 出卡并进 **闪卡页**；知识中心钮去掉或只保留与闪卡无关的设置（若有） |
| 闪卡页「闪卡记忆中心 / 今日概览 / Mastered / 开始复习」仪表盘 | 进去 **先平铺展示卡**（对齐图片页）。「待复习」可以是卡库上的 **一个动作**，进入 Host `scheduled` 轮次，不把首页改成学习仪表盘 |
| 右栏 `FlashcardsPanel` 当第二套闪卡家 | 到期卡若有需要，从闪卡页进入；或缩成与 CardStore 同一数据源的一眼预览 |
| 知识中心出卡结果 →「打开复习会话」跳聊天 | 出完留在 **闪卡页**；聊天只做当场撕卡预览 |
| 一套卡主交互「‹ 上一张 / 下一张 ›」分页条 | **同一窗口撕卡动画 + 「下一张」按钮** |
| 按钮文案「撕掉」 | **「下一张」**（动画仍可称 tear）；最后一张 **「结束浏览」**，完成页 **「已浏览 N 张」** |
| 卡内划词复制提示词 / `composer/propose-text` 冒充讲解 | 就地 hint / explain；不写 clipboard、不写 transcript |
| 知识中心 Wiki 搜索抽屉、`/wiki` 斜杠入口 | 删除（旧挂件） |
| 按文件夹「套 1 / 套 2」编号 UI | 删除；库内平铺 + 用户删留 |
| 以学代审、卡片「能不能用」状态、今日待刷首页 | 删除相关文案与入口 |
| 入口矩阵（五进四出）、StudySpace、三栏复习桌 | 删除方案与残留 UI |

### 8.2 文档作废

- 旧稿：`StudySpace`、入口矩阵、以学代审、每日复习仪式、`docs/superpowers/specs/2026-08-17-knowledge-center-loop-repair-design.md` 里「打开复习会话 / 到期 FSRS 右栏为主」部分 — **以本文为准**。

### 8.3 保留并迁入闪卡页

原 `KnowledgeCenterPanel` 产卡环：`scan-folder`、`index-folder`、`generate`、进度环、文件勾选、`forget-folder`、`open-source` — **能力原样保留**，Presentation 改在 `FlashcardsWorkspaceView`（或等价全屏页）。

`composer/propose-text` 作为 Canvas Artifact 通用能力保留；闪卡划词不再走该路径。

## 11. 验收

1. 侧栏「闪卡」一点，看见所有已落盘卡（含聊天出的）。  
2. 文件夹 / 工作空间 → 向量库 → 出卡，在闪卡页可完成。  
3. 聊天 / 文档划词 →「生成闪卡」→ **恰好一张**原子卡进会话与 CardStore；闪卡页可见。  
4. 平铺；点一套进入复习台后可撕到下一张（同一撕卡契约）；按钮文案是「下一张」；最后一张「结束浏览」；完成页「已浏览 N 张」，不写「掌握」。  
5. 可删一张 / 删一套；改 = 删了再出。  
6. 拖选与单击文字不翻面；Space 与显式按钮翻面。
