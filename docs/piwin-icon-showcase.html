piwin Coding Agent Visual Identity

SVG 图标设计预览规范

为 piwin (Private AI Coding Agent Shell) 打造的高精矢量图标组件库。适配 Desktop (Tauri 2)、CLI 以及 UI 工具栏。包含品牌 App Icon、Kernel 架构、Tool 扩展及 Workflow 语义图标。

图标尺寸:

App Logo / Branding Candidates (128x128 细节渲染)

Logo A · Neon Core #logo-neon

极简金属基板 + 琥珀金与电光青双色星核，融合 π 与 Terminal 手势。

Logo B · Cyber Shell #logo-shell

深色 Cyber 终端窗口外壳，直观体现 Host Shell + Pi Kernel 的层级。

Logo C · Swarm Matrix #logo-swarm

多智能体 (Subagent Swarm) 节点拓扑构成的 π 抽象星阵。

Logo D · Sidecar Dual #logo-sidecar

双重叠加叠层面板，象征 Client 壳层与私有 Host 侧边栏/远端算力的解耦融合。

Agent Core & Architecture (24x24 矢量 API/UI 图标)

Agent Kernel pi-core

Pi 核心内核标识，微调圆润末端与信号光点。

Host Service host-server

独立/侧边栏 Host 守护进程与服务节点。

Shell Prompt terminal-exec

CLI & 终端 Bash 执行命令指示符。

Subagent Swarm subagent-swarm

子 Agent 动态派生与多智能体并行调度。

Dual Mode (SDK/RPC) dual-mode

PiSdkAdapter 与 PiRpcAdapter 无缝双模切换。

Fast Run / Job async-task

后台 Task 高效异步调度与长任务触发。

Capabilities & Extension Tools (24x24 扩展与工具)

Skills Marketplace tool-skills

技能包、Prompt 模板与微流工作流载入。

MCP Interconnect tool-mcp

Model Context Protocol 插件与服务桥接。

Artifact Sandbox tool-artifact

交互式安全渲染沙盒与 HTML/React 产物预览。

Web Automation tool-browser

网页 Fetch、自动化 Search 及 Web 页面抓取。

Vision & Media tool-media

多模态图片传入、截图分析与媒体视觉审计。

Permission Gate tool-security

分层安全策略 (auto / ask-all / bypass) 拦截闸口。

Workflow, State & Memory (工作流与上下文)

Session Plan flow-plan

Task 规划与 PlanExecutionSummary 阶段跟踪。

Context Vault flow-memory

Session 历史向量索引与长文本 Memory 检索。

Git Workspace flow-git

Git 分支、提交快照与变更 Diff 管理。

Config Root (~/.piwin) flow-config

配置根目录、偏好设置与系统环境校验。
