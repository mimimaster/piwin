  2|
  3|## Status
  4|
  5|Proposed (2026-08-10)
  6|
  7|## Context
  8|
  9|piwin currently exposes one Host-owned `web_search` tool. It can aggregate
 10|multiple configured external sources, but some chat models can also perform
 11|provider-native web search and return grounded content directly. Advertising
 12|both mechanisms to one agent creates duplicate searches, inconsistent
 13|citations, unclear permissions, and unnecessary cost.
 14|
 15|Video generation already has a `video-generation` model capability and a
 16|provider-neutral settings/runtime flow (ADR 0034). Its remaining usability gap
 17|is discovery: users should not have to re-enter a model that the provider has
 18|already returned, but name-only inference can confuse video understanding with
 19|video generation.
 20|
 21|## Decision
 22|
 23|### 1. Distinguish model-native search from the external tool family
 24|
 25|Add `native-web-search` to `ModelCapability`. The UI label is **内置搜索**,
 26|not the ambiguous **搜索**. The existing `web-search` session tool family and
 27|its public `web_search` tool continue to mean piwin's external search service.
 28|
 29|A capability tag is a declaration, not executable routing. Native search is
 30|ready only when all of the following are true:
 31|
 32|- the selected chat model is enabled and tagged `native-web-search`;
 33|- the active Pi SDK/RPC adapter can express native search for that provider;
 34|- the provider-native feature is controllable for the request.
 35|
 36|If an adapter cannot support the provider's native mechanism, the Host reports
 37|the capability as unavailable instead of pretending the label enabled it.
 38|
 39|### 2. Resolve exactly one search backend for each generation
 40|
 41|Add a search-route policy distinct from the existing external multi-source
 42|`searchStrategy`:
 43|
 44|```ts
 45|type SearchRoutePolicy =
 46|  | 'native-first'
 47|  | 'external-first'
 48|  | 'native-only'
 49|  | 'external-only';
 50|```
 51|
 52|`external-first` is the migration default because it preserves current
 53|behavior, permission handling, and citation rendering. Host Runtime resolves
 54|the route from the selected model, adapter support, configured external search
 55|sources, and policy:
