## piwin 桌面壳子视觉重设计（"Daybreak 破晓"）

用户要求：给 piwin GUI 换漂亮积极的壳子，可自由调整布局。

### 改了什么
- **主题系统**（核心）：`apps/desktop/src/appearance-tokens.ts` 全面换 palette——深色=暖墨+日出珊瑚 `#ff8359/#ffb37e`，浅色=暖纸+蜜柑 `#e85d1f/#f4955c`；派生 token（accent-soft/surface-selected/border-interactive 等）改为从 `tokens.accent` 用 color-mix 派生，不再硬编码蓝色 rgba；圆角整体加大（sm7/control8/surface10/overlay14）；阴影从 none 改为暖色软阴影。两个 bundled theme.json 同步 v5.0.0。
- **氛围**：`region-shell.css` `.workspace` 加日出环境光（顶部 radial-gradient 纯背景层，无堆叠副作用）；context-bar/chat-stream 背景改透明让光透过来。
- **组件打磨**：侧栏"新会话"CTA 和品牌标改渐变+发光（light 模式文字切白）；空状态 hero 标题渐变文字+eyebrow 用 accent；建议卡 hover 上浮；用户气泡暖色填充；composer 卡片 18px 圆角+暖阴影+focus 光环；发送按钮渐变。
- **ui-kit 修复**：`piwin-ui-provider.tsx` 的 `buildAccentScale` 原来硬编码蓝色 ramp（浅蓝+深蓝夹着 manifest accent），导致浅色模式下 Mantine filled 按钮/悬浮漏出纯蓝 `#0074e8`——改为从 accent 用 mixHex 生成全色相一致的 10 级 ramp；`primaryShade` 改对象形式 `{light:5,dark:5}`（数字形式在与默认 `{light,dark}` 对象 deepMerge 时可能丢失）。
- **原生控件**：`base.css` 加 `accent-color: var(--accent)`（range/checkbox/radio/progress），修复原生滑杆/复选框渲染 UA 蓝。
- **theme-store**：`ensureBundledThemesInstalled` 原来只装缺失、永不刷新——加版本比较，bundled 更新时覆盖安装副本。
- mock host 主题版本号 3.0.0→5.0.0。

## 右栏拖拽抖动修复
用户反馈右侧展开/收缩有概率触发对话区抖动。子代理 + 手动实证定位根因：`pointermove` 每帧触发 setState + `onLiveWidthCommit`（约 100+/s），App.tsx 的 `useEffect` 又以 `widthPx` 为依赖重复触发 `adjustWindowOutwardForRightPanelWidth` → Tauri `setSize` 异步竞态，OS 窗口宽度滞后于指针 → `minmax(0,1fr)` stage 宽度抖动，居中的 chat 列随之左右漂移。

修复（`hooks/use-right-panel-resize.ts` + `App.tsx` + `styles/region-inspector.css`）：
1. pointermove 加 rAF 批处理（一个 frame 内最多 1 次 setState + 1 次 commit）。
2. App.tsx 的 resize effect 拆成两个：一个依赖 `[layoutMode, rightPanelOpen]` 仅处理开关；另一个在 `!isResizing` 时同步窗口尺寸，去掉拖拽中的冗余 setSize。
3. `.right-panel.is-resizing` 关闭 transition（防止任何残留过渡）。

e2e 50/50 通过。Playwright headless 模式下 hit-test 与用户的真实鼠标有差异（`.right-panel` `overflow: hidden` 会裁掉 `left:-4px` 的手柄，控件提交捕获需精准点击可见区，实测脚本写的点击可能不命中）——实际手感验证需要用户在原生窗口或 `dev:tauri` 下确认。
